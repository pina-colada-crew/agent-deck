# Research: dnd-kit Patterns for Session and Session Group Drag-and-Drop

**Date**: 2026-02-02T20:17:41+01:00

## Research Question

How does coding-platform/client use dnd-kit for file and folder dragging? This research informs implementing similar functionality for sessions (analogous to files) and session groups (analogous to folders) in agent-deck.

## Summary

The coding-platform client implements a comprehensive drag-and-drop system using `@dnd-kit` with the following key patterns:

1. **Hierarchical DndContext** - Separate contexts for different drag domains (file tree, tabs)
2. **Layered Context Providers** - DragStateContext (state) + DragContext (validation logic)
3. **Type-based validation** - `type: "file" | "folder"` distinguishes draggable items
4. **Path-based identification** - Items identified by unique path strings
5. **Auto-expand on hover** - Folders expand after 1-second hover during drag
6. **Multi-layer validation** - Prevents invalid operations (self-move, circular drops)

## Detailed Findings

### 1. DndContext Configuration

**File Tree Context** (`FileTree.tsx`):
```typescript
<DndContext
  sensors={sensors}
  collisionDetection={rectIntersection}
  onDragStart={handleDragStart}
  onDragEnd={(event) => handleDragEnd(event)}
  onDragCancel={handleDragCancel}
  measuring={{
    droppable: {
      strategy: MeasuringStrategy.Always,  // Continuously measures droppables
    },
  }}
>
```

**Key Configuration Choices**:
- `rectIntersection` collision detection - Best for hierarchical tree structures
- `MeasuringStrategy.Always` - Required for dynamic droppables (expanding folders)
- Separate handlers for start, end, and cancel events

**Sensor Configuration**:
```typescript
const sensors = useSensors(
  useSensor(PointerSensor, {
    activationConstraint: {
      distance: 5,  // Require 5px movement before drag starts
    },
  })
);
```

```typescript
const { attributes, listeners, setNodeRef } = useDraggable({
```

**Key Pattern**: The entire item is the drag handle (no separate handle element).

```typescript
  setDroppableRef(el);

```

**Validation Function** (prevents invalid drops):
```typescript
function isFolderDroppable(node: FileNode) {
  const draggedNode = findNodeByPath(draggedItemFilePath);

  // Prevent dropping folder into its own subfolder
  const isSubfolderOfTheFolderBeingDragged =
    draggedNode?.type === "directory" && isDescendant(draggedNode, node);

  // Prevent dropping into direct parent (no-op)
  const isDirectParentFolderOfTheItemBeingDragged =
    draggedNode && isDirectDescendant(findNodeByPath(node.path)!, draggedNode.path);

  return !isSubfolderOfTheFolderBeingDragged && !isDirectParentFolderOfTheItemBeingDragged;
}
```

### 5. Drag Event Handlers

**handleDragStart** (`useDragHandlers.ts`):
```typescript
const handleDragStart = (event: DragStartEvent) => {
  const { active } = event;
  setDraggedItemFilePath(active.id.toString());

  if (active.data.current) {
    setActiveDraggable({
      path: active.id.toString(),
      type: active.data.current.type,
      name: active.data.current.name,
      isReadOnly: false,
    });
  }
};
```

**handleDragEnd** (`useDragHandlers.ts`):
```typescript
const handleDragEnd = async (event: DragEndEvent) => {
  const { active, over } = event;

  if (!over || active.id === over.id) {
    resetDragState();
    return;
  }

  const draggedNode = findNodeByPath(active.id.toString());
  const droppedOnNode = findNodeByPath(over.id.toString());

  // Validate move
  const moveValidation = validateMove({
    sourcePath: draggedNode.path,
    targetDirectoryPath: normalizedTargetDir,
    pathExists: (path) => Boolean(findNodeByPath(path)),
    entityType: draggedNode.type === "directory" ? "folder" : "file",
  });

  if (!moveValidation.ok) {
    toast.error(moveValidation.message);
    resetDragState();
    return;
  }

  // Execute move operation
  await executeWorkspaceOperation({
    operation: WorkspaceOperationType.FILE_MOVE,
    path: draggedNode.path,
    targetDirectoryPath: normalizedTargetDir,
  });
};
```

### 6. Auto-Expand on Hover

**FolderItem.tsx** - 1-second hover triggers expansion:
```typescript
useEffect(() => {
  if (isOver && isDroppable && !isFolderExpanded) {
    expandTimerRef.current = setTimeout(() => {
      toggleFolderExpansion(node.path);

      // Refresh measurements after DOM updates
      requestAnimationFrame(() => {
        refreshDroppableMeasurements?.();
      });
    }, 1000);
  } else {
    if (expandTimerRef.current) {
      clearTimeout(expandTimerRef.current);
      expandTimerRef.current = null;
    }
  }
}, [isOver, isDroppable, isFolderExpanded, node.path, toggleFolderExpansion]);
```

### 8. Root Drop Zone

**FileTree.tsx** - Special zone for dropping at root level:
```typescript
const RootDropZone: React.FC<{...}> = ({ onDrop, onOver, onOut }) => {
  const { setNodeRef, isOver } = useDroppable({
    id: "drop-to-root",
    data: {
      accept: ["file", "folder"],
    },
  });

  useEffect(() => {
    if (isOver) onOver();
    else onOut();
  }, [isOver, onOver, onOut]);

};
```

## Architecture Insights

### Recommended Pattern for Agent-Deck

**Mental Mapping**:
| Coding Platform | Agent-Deck |
|-----------------|------------|
| File | Session |
| Folder | Session Group |
| File Tree | Session List |
| Tab Reordering | Session Reordering within Group |

**Suggested Implementation**:

1. **Create SessionNode type**:
```typescript
interface SessionNode {
  id: string;
  name: string;
  type: "session" | "group";
  groupId?: string;  // Parent group (null for root)
  children?: SessionNode[];  // For groups
}
```

2. **Two-layer context pattern**:
- `SessionDragStateContext` - Raw drag state
- `SessionDragContext` - Validation logic (is group droppable?)

3. **Validation rules**:
- Cannot drop group into its own subgroup
- Cannot drop session into its current group (no-op)
- Sessions can only be dropped into groups or root
- Groups can be dropped into other groups or root

4. **DndContext configuration**:
```typescript
<DndContext
  sensors={sensors}
  collisionDetection={rectIntersection}
  measuring={{ droppable: { strategy: MeasuringStrategy.Always } }}
  onDragStart={handleDragStart}
  onDragEnd={handleDragEnd}
  onDragCancel={handleDragCancel}
>
```

5. **Auto-expand groups** on 1-second hover during drag

6. **Visual feedback**:
- `bg-drop-target` on valid drop zones
- `opacity-40` on dragged item's original position
- DragOverlay showing ghost preview

## Open Questions

1. **Nested groups**: Will session groups support nesting? The file tree implementation supports infinite nesting.

2. **Sorting within groups**: Should sessions be sortable within a group (like tabs)? Would use `@dnd-kit/sortable` with `verticalListSortingStrategy`.

3. **Cross-group moves**: When moving a session between groups, should there be animation?

4. **Persistence**: How should the new session/group structure be persisted after drag operations?

5. **Undo support**: Should moves be undoable?
